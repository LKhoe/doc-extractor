To use Gemini Nano, enable these flags in Chrome (version 128+):

  1. Open chrome://flags/#optimization-guide-on-device-model → set to Enabled BypassPerfRequirement
  2. Open chrome://flags/#prompt-api-for-gemini-nano → set to Enabled
  3. For multimodal support, also enable chrome://flags/#prompt-api-for-gemini-nano-multimodal-input
  4. Relaunch Chrome
  5. Open chrome://components, find Optimization Guide On Device Model and click Check for update

After the model downloads (~1.7 GB), the Gemini Nano engines will show as Ready.
